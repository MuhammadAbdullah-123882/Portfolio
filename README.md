# Portfolio Website

A minimal, single-page personal portfolio built with plain HTML, CSS, and JavaScript — hosted on GitHub Pages.

## 🔗 Live Site

https://muhammadabdullah-123882.github.io/Portfolio/

## 📌 About

This is my personal portfolio, showcasing my technical background with a focus on **Generative AI** and **Agentic AI**. It's designed to be clean, fast-loading, and free of unnecessary frameworks or bloat.

## ✨ Features

- **Minimal, clean design** — single-page layout with no clutter
- **Custom photo section** — profile picture displayed in a connected graph-shaped visual
- **Project showcase** — placeholder sections ready to be filled in as projects are completed
- **Fully static** — no build step, no dependencies, just HTML/CSS/JS
- **Responsive** — works across desktop and mobile

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
- [GitHub Pages](https://pages.github.com/) for hosting

## 📁 Project Structure

```
├── index.html          # Main page
├── style.css           # Styling
├── script.js           # Interactivity (graph photo section, etc.)
├── images/             # Images & assets
├── favicon.ico         # Site favicon
└── README.md
```

## 🚀 Running Locally

Clone the repo and open `index.html` in your browser — no build tools required.

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
open index.html
```

## 🌐 Deployment

This site is deployed via **GitHub Pages**. Any push to the `main` branch automatically updates the live site.
